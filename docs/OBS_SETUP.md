# ตั้งค่า OBS

## Overlay 1080p

เพิ่ม Source:

```text
Source Type: Browser
URL:         http://127.0.0.1:3000/overlay
Width:       1920
Height:      1080
```

เหมาะกับ canvas 1920x1080

เหมาะกับ canvas 2560x1440

## เสียงเอฟเฟกต์ (ถ้าต้องการ)

ปกติ overlay ไม่มีเสียง ถ้าอยากให้คนดูได้ยินเสียงตอน pick / ban / เวลาใกล้หมด:

1. เอาไฟล์เสียงไปวางในโฟลเดอร์ `sounds` ของ media ตั้งชื่อตามนี้ (.mp3 หรือ .wav ก็ได้)

   ```text
   pick.mp3            ตอนเลือกฮีโร่
   ban.mp3             ตอนแบนฮีโร่
   timer-warning.mp3   ตอนนับถอยหลังสิบวินาทีสุดท้าย ดังทุกวินาที (10, 9, ... 1)
   ```

   โฟลเดอร์นี้แอพสร้างให้เองตอนเปิด ไม่ต้องสร้างเอง หาไม่เจอให้เปิดจากเมนู
   **ROV Tool → Open Sounds Folder** หรือดูที่บรรทัด "Sound effects" ในหน้าต่าง
   console ตอนเปิดแอพ ซึ่งพิมพ์ path เต็มไว้ให้

   - เปิดด้วย START_APP.cmd: `%APPDATA%\rov-overlay-tool\media\sounds\`
   - ติดตั้งจาก .exe: `%APPDATA%\ROV Overlay Tool\media\sounds\`
   - รัน `npm start` เฉยๆ (ไม่ผ่าน Electron): `public\images\sounds\`

2. URL ที่ก๊อปจากหน้า Control หรือหน้าทัวร์นาเมนต์มี `?sfx=1` ติดมาให้แล้ว
   ถ้าพิมพ์เองต้องเติมท้าย URL ของ browser source **อันเดียว** เท่านั้น

   ```text
   URL: http://127.0.0.1:3000/overlay?sfx=1
   ```

   ใส่ให้อันเดียวจริงๆ overlay 1080p, 1440p และหน้า result รับข้อมูลชุดเดียวกัน
   ถ้าเปิดเสียงสองอันจะได้ยินทุกเสียงซ้ำสองครั้งเหลื่อมกันนิดหน่อย

3. ใน OBS เปิด Properties ของ browser source แล้วติ๊ก **Control audio via OBS**
   และอย่าติ๊ก **Shutdown source when not visible**

   overlay ต้องทำงานค้างอยู่ตลอดเสียงถึงจะออก ถ้าติ๊กช่องนั้นไว้ OBS จะปิดหน้าเว็บทิ้ง
   ทุกครั้งที่สลับไปซีนอื่น และ OBS ผสมเสียงเฉพาะ source ที่อยู่ในซีนที่ออกอากาศอยู่
   ดังนั้น overlay ต้องอยู่ในซีนนั้นด้วย ไม่ใช่อยู่แค่ในซีนอื่น

   ถ้าไม่ติ๊ก เสียงจะออกลำโพงของเครื่องเฉยๆ คนดูไม่ได้ยิน
   ติ๊กแล้วมันจะไปโผล่ใน Audio Mixer ปรับระดับเสียงได้จากตรงนั้น

ระดับเสียงของแต่ละเสียง (pick / ban / timer) ปรับได้ที่หน้า Control Panel ในแผง
**Sound effects** เลื่อนแล้วมีผลกับ overlay ที่เปิดค้างใน OBS ทันที ไม่ต้อง Refresh source
ปุ่ม TEST ในแผงนั้นเล่นให้ฟังที่หน้า Control เอง ไม่ได้ออกอากาศ
ค่าที่ตั้งไว้ไม่หายเวลากด RESET MATCH หรือเปิดแมตช์ถัดไปขึ้นจอ

ตัวเลือกเพิ่มเติมที่ต่อท้าย URL ได้:

```text
&vol=0.5   ระดับเสียง 0 ถึง 1 (ไม่ใส่ = 1 คือดังเต็มไฟล์)
&v=2       บวกเลขนี้ทีละหนึ่งหลังเปลี่ยนไฟล์เสียง OBS จำไฟล์เก่าไว้แน่นมาก
```

### ทดสอบในเบราว์เซอร์ธรรมดา (ไม่ใช่ใน OBS)

เปิด `http://127.0.0.1:3000/overlay?sfx=1` ในเบราว์เซอร์แล้วจะ **ไม่ได้ยินอะไรเลย**
จนกว่าจะคลิกบนหน้านั้นหนึ่งครั้ง นี่คือกฎของเบราว์เซอร์ ไม่ใช่บั๊ก:
หน้าเว็บที่ผู้ใช้ยังไม่เคยแตะ ห้ามส่งเสียงเอง

หน้า overlay รู้เรื่องนี้ ถ้าโดนกั้นอยู่มันจะขึ้นปุ่ม **Click to enable sound**
ที่มุมซ้ายล่าง กดที่ไหนก็ได้บนหน้าหนึ่งครั้ง เสียงจะทำงานตลอดจนกว่าจะปิดหน้า

ปุ่มนี้ **ไม่ขึ้นใน OBS** เพราะ OBS ไม่มีข้อห้ามนี้ (หน้าเว็บใน OBS เล่นเสียงเองได้เลย)
ถ้าขึ้นในนั้นมันจะไปนั่งค้างบนจอคนดูตลอดรายการ เพราะไม่มีใครคลิกให้

### ไม่มีเสียง ทำยังไง

เปิดหน้าตรวจเสียง มันบอกให้เลยว่าติดตรงไหน:

```text
http://127.0.0.1:3000/sfx-test
```

เอาไปเปิดเป็น browser source **ใน OBS** ด้วย เพราะสิ่งที่อยากรู้คือ OBS ทำอะไรได้บ้าง
หน้านั้นพิมพ์คำตอบบนจอเลย ไม่ต้องเปิด console (ซึ่งใน OBS ก็เปิดไม่ได้)

อ่านผลแบบนี้:

- **ขึ้น missing** = ชื่อไฟล์หรือโฟลเดอร์ผิด แก้ชื่อให้ตรง
- **Autoplay blocked** = OBS ไม่ยอมให้หน้าเว็บเล่นเสียงเอง ให้อัปเดต OBS
- **Autoplay allowed แต่ overlay ยังเงียบ** = URL ของ source ยังไม่มี `?sfx=1`
  หรือยังไม่ได้ Refresh source
- **กดปุ่ม PLAY ในหน้านั้นแล้วยังไม่ได้ยิน** = เสียงไม่ได้ออกมาถึงหูเลย
  ให้ติ๊ก Control audio via OBS แล้วดูว่า source ไม่ได้ถูก mute ใน Audio Mixer

## คำแนะนำ

- เปิดแอพหรือ server ก่อนเปิด OBS scene
- ถ้า overlay ไม่อัปเดต ให้คลิกขวา Browser Source แล้ว Refresh
- ถ้าใช้หลายเครื่อง ต้องให้เครื่อง OBS เข้าถึง IP ของเครื่องที่รันแอพได้
- ถ้าใช้เครื่องเดียวกัน แนะนำใช้ `127.0.0.1`
