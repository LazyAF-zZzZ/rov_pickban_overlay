# ROV Pick/Ban Overlay Tool

[![Platform](https://img.shields.io/badge/platform-Windows-2563eb)](https://github.com/LazyAF-zZzZ/rov_pickban_overlay)
[![OBS](https://img.shields.io/badge/OBS-Browser%20Source-7c3aed)](https://obsproject.com/)
[![License](https://img.shields.io/badge/license-Free%20Non--Commercial-ef4444)](LICENSE.md)
[![Release](https://img.shields.io/badge/download-Releases-16a34a)](https://github.com/LazyAF-zZzZ/rov_pickban_overlay/releases)

ROV Pick/Ban Overlay Tool คือแอพสำหรับทำหน้าจอ Draft Pick / Ban ของเกม ROV เพื่อใช้กับ OBS, งานถ่ายทอดสด, รายการชุมชน, ทัวร์นาเมนต์เล็ก-กลาง และทีมงานที่ต้องการ overlay ใช้งานง่ายโดยไม่ต้องเขียนโค้ดเอง

ตั้งแต่รุ่น 2.0 เป็นต้นมา ไม่ได้มีแค่หน้าดราฟต์อีกแล้ว แต่จัดทัวร์นาเมนต์ได้ทั้งรายการ ตั้งแต่ทะเบียนทีม สายการแข่ง ตารางคะแนน ไปจนถึงกราฟิกสำหรับ OBS ที่อ่านสถิติจากดราฟต์ที่บันทึกไว้เอง

**ข้อมูลทุกอย่างอยู่ในเครื่องของคุณ** ไม่ต้องสมัครสมาชิก ไม่ต้องต่อเน็ต ไม่มีอะไรถูกส่งออกไปข้างนอก

โปรเจกต์นี้แจกให้ใช้งานฟรี แต่ห้ามนำไปขาย ขายต่อ ให้เช่า รวมในแพ็กเกจเสียเงิน หรืออ้างว่าเป็นผลงานของตัวเอง

ถ้าคุณต้องการใช้งานอย่างเดียว ให้ดาวน์โหลดไฟล์ `.exe` จากหน้า Releases:

## จุดเด่น

**คุมดราฟต์**

- Control Panel สำหรับควบคุมทีม, ผู้เล่น, score, pick, ban และ timer
- ค้นหาฮีโร่ด้วยการพิมพ์ และสลับ hero pick ได้โดยไม่สลับชื่อผู้เล่น
- เปลี่ยนตำแหน่งผู้เล่น (Jungle / Carry / Mid lane / Off lane / Support) ได้จากหน้า Control ระหว่างเกม ไอคอนหลังช่องพิคเปลี่ยนทันที
- ตั้งชื่อรายการ, match title, เกม, BO และข้อมูลทีมได้
- คีย์ลัดระดับระบบ กดได้แม้ไม่ได้อยู่ที่หน้าต่างโปรแกรม

**จัดทัวร์นาเมนต์**

- แพ้คัดออก, แพ้สองครั้งคัดออก, พบกันหมด และแบ่งกลุ่ม จับสายให้อัตโนมัติ
- กรอกคะแนนแล้วผู้ชนะเลื่อนไปรอบถัดไปเอง มีตารางคะแนนของรอบแบ่งกลุ่ม และส่งทีมที่ผ่านเข้ารอบน็อกเอาต์ได้ในรายการเดียวกัน
- ทะเบียนทีม เก็บชื่อทีม ผู้เล่น ตำแหน่ง และโลโก้ไว้ที่เดียว ใช้ร่วมกันทุกทัวร์นาเมนต์ แต่ละทีมมีหน้าโปรไฟล์พร้อมประวัติการแข่ง
- ดราฟต์ทุกเกมถูกบันทึกอัตโนมัติ เปิดคู่ไหนขึ้นจอ ดราฟต์ของคู่นั้นก็ถูกเก็บเอง ไม่ต้องกรอกอะไรเพิ่ม

**กราฟิกสำหรับ OBS**

- Overlay ดราฟต์ 1920x1080 และ 2560x1440
- หน้า Result สำหรับสรุป draft
- รายชื่อทีม, กระดานสถิติ (หยิบบ่อยสุด / โดนแบนบ่อยสุด / อัตราชนะ), ตารางคะแนน, หัวต่อหัว, ตัวที่แต่ละทีมหยิบและแบนในรายการ และดราฟต์ของรอบก่อนหน้า
- ทั้งหมดอ่านจากดราฟต์ที่บันทึกไว้แล้ว ไม่ต้องกรอกซ้ำ

**อื่นๆ**

- เสียงเอฟเฟกต์ตอนพิค ตอนแบน และช่วงสิบวินาทีสุดท้าย ปรับระดับแยกกันได้
- สองภาษา ไทยและอังกฤษ สลับด้วยปุ่ม TH/EN บนแถบด้านบน (หน้ากราฟิกที่ออกอากาศเป็นภาษาอังกฤษเสมอ)
- คู่มือในตัวที่หน้า Guide เปิดอ่านได้ตอนออฟไลน์
- สำรองและกู้คืนข้อมูล ทีม โลโก้ สายการแข่ง และดราฟต์ทั้งหมดรวมเป็นไฟล์เดียว
- อัปโหลดภาพพื้นหลังของตัวเองได้ที่หน้า Design
- เปิดเป็นแอพ Windows ด้วย Electron และมีระบบยืนยันเงื่อนไขการใช้งานก่อนเข้าแอพ

## ใช้กับ OBS

เพิ่ม `Browser Source` ใน OBS ใช้ URL เดียวกันทั้งสองขนาด แล้วเลือกขนาดจากปุ่ม SIZE

สำหรับ 1080p:

```text
URL:    http://127.0.0.1:3000/overlay
Width:  1920
Height: 1080
```

สำหรับ 1440p ใช้ URL เดิม แต่ตั้งขนาด Browser Source เป็น:

```text
URL:    http://127.0.0.1:3000/overlay
Width:  2560
Height: 1440
```

หน้า Result ก็เปลี่ยนตามปุ่ม SIZE เหมือนกัน

> **เรื่องเสียง** เสียงถูกเล่นที่หน้า overlay ไม่ใช่ที่หน้าต่างโปรแกรม ต้องเปิดหน้า overlay ค้างไว้ (กดปุ่ม เปิด ที่รายการ browser source หรือเปิดจากเมนู `ROV Tool`) ปิดเมื่อไหร่เสียงหยุด และ URL ที่คัดลอกจากในแอพจะมี `?sfx=1` ต่อท้ายให้แล้ว ซึ่งเป็นตัวเปิดเสียง

อ่านรายละเอียดเพิ่มได้ที่:

```text
docs/USER_GUIDE.md    คู่มือผู้ใช้ ไทย/อังกฤษ อ่านอันนี้ก่อน
docs/OBS_SETUP.md     ตั้งค่า OBS แบบละเอียด
```

## เลือกขนาดหน้าจอ

เลือก `1080p` หรือ `1440p` ได้ที่ปุ่ม **SIZE** มุมขวาบนของ Control Panel
เลือกครั้งเดียว ทั้งหน้า Overlay และ Result จะเปลี่ยนตามทันที ไม่ต้องแก้ URL

| ขนาด | ตั้งค่า Browser Source ใน OBS |
|---|---|
| 1080p | 1920 x 1080 |
| 1440p | 2560 x 1440 |

> ตัวแอพเปลี่ยนขนาดหน้าเว็บให้เอง แต่ **ขนาดของ Browser Source ใน OBS ต้องตั้งเอง** ให้ตรงกัน

URL เดิม `/overlay-1440` ยังใช้ได้อยู่ สำหรับคนที่ใส่ไว้ใน OBS แล้ว
URL นั้นจะล็อกที่ 1440p เสมอ ไม่เปลี่ยนตามปุ่ม SIZE

ในตัวแอพสามารถเปิดหน้า Overlay และ Result ได้จากเมนู `ROV Tool`

## ใช้ภาพที่ออกแบบเอง

เปิดหน้า **Design** (ปุ่ม `DESIGN` มุมขวาบนของ Control Panel) แล้วอัปโหลดภาพได้ 4 จุด

| จุด | ครอบคลุม |
|---|---|
| Overlay Top | แถบบน: ban, ชื่อทีม, score, timer |
| Overlay Bottom | แถบล่าง: การ์ด pick ทั้ง 10 ช่อง |
| Result Top | หน้า result ครึ่งบน (ทีมน้ำเงิน) |
| Result Bottom | หน้า result ครึ่งล่าง (ทีมแดง) |

ออกแบบที่อัตราส่วน 16:9 ไฟล์เดียวใช้ได้ทั้ง 1080p และ 1440p
ทำพื้นที่โปร่งใสไว้ตรงที่อยากให้เห็นรูปฮีโร่

มีสวิตช์สองตัวแยกกัน

- `USE MY DESIGN` เปิดใช้ภาพที่อัปโหลด
- `SHOW BUILT-IN PANELS` ถ้าเอาออก จะเหลือแต่ภาพของคุณ ไม่มีกรอบเดิมของแอพมาทับ

ถ้าไม่อัปโหลดอะไรเลย หน้าตาจะเหมือนเดิมทุกอย่าง

ไฟล์เหล่านี้เป็นข้อมูลของคุณ ไม่ได้อยู่ในโปรเจกต์ git และไม่ได้ถูกแพ็คลงตัวติดตั้ง

## วิธีใช้จาก source code

สำหรับคนที่ต้องการแก้ไขหรือ build เอง

ติดตั้ง Node.js LTS ก่อน จากนั้นรัน:

```powershell
npm.cmd install
npm.cmd run app
```

ถ้าต้องการรันเป็น web server อย่างเดียว:

```powershell
npm.cmd start
```

## Build เป็นไฟล์ .exe

สร้างไฟล์ portable:

```powershell
npm.cmd run portable
```

สร้างทั้งตัวติดตั้งและ portable:

```powershell
npm.cmd run dist
```

ไฟล์ build จะอยู่ใน:

```text
dist/
```

มีไฟล์ช่วยกดรันบน Windows:

```text
START_APP.cmd
BUILD_PORTABLE_EXE.cmd
BUILD_SETUP_EXE.cmd
```
