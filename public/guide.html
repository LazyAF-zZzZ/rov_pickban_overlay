Language

Everything runs on this computer. No account, no internet, nothing stored online.

ทุกอย่างทำงานในเครื่องนี้ ไม่ต้องสมัครอะไร ไม่ต้องต่อเน็ต ไม่มีข้อมูลถูกเก็บออนไลน์

1
Open the app
เปิดโปรแกรม
  1. Double-click START_APP.cmd.
  2. Leave the window open for as long as you are streaming.

The pages you need are on the bar at the top of every screen.

  1. ดับเบิลคลิก START_APP.cmd
  2. เปิดหน้าต่างทิ้งไว้ตลอดเวลาที่ไลฟ์

หน้าที่ต้องใช้อยู่บนแถบด้านบนของทุกหน้า

2
Put the overlay into OBS
เอา overlay ใส่ OBS
  1. Go to CONTROL and scroll to OBS browser sources.
  2. Click COPY URL on Overlay 1080p, or 1440p if your canvas is 2560×1440.
  3. In OBS: + → Browser, paste the URL, Width 1920, Height 1080.
  4. Tick Control audio via OBS so viewers hear the sound effects.
  5. Leave Shutdown source when not visible unticked, so the overlay keeps running and keeps its sound.
  6. Add Result the same way if you want the winner screen.

If COPY URL does nothing, click the URL text once — it selects itself — then press Ctrl C.

  1. ไปหน้า CONTROL เลื่อนลงไปที่ OBS browser sources
  2. กด COPY URL ของ Overlay 1080p ถ้า canvas เป็น 2560×1440 ให้ใช้ 1440p
  3. ใน OBS: + → Browser วาง URL ตั้ง Width 1920 Height 1080
  4. ติ๊ก Control audio via OBS เพื่อให้คนดูได้ยินเสียง
  5. อย่าติ๊ก Shutdown source when not visible เพื่อให้ overlay ทำงานค้างไว้และเสียงไม่หาย
  6. ถ้าอยากได้หน้าประกาศผู้ชนะ ให้เพิ่ม Result ด้วยวิธีเดียวกัน

ถ้ากด COPY URL แล้วไม่มีอะไรเกิดขึ้น ให้คลิกที่ตัว URL หนึ่งครั้ง มันจะเลือกให้เอง แล้วกด Ctrl C

3
Run a quick match
คุมแมตช์แบบเร็ว

For a single match that is not part of a tournament.

  1. Go to CONTROL.
  2. Type the team names, or choose a saved team from From registry.
  3. Type the player names.
  4. During the draft type hero names into HERO PICK and BAN, then press Enter.
  5. Drive the clock with START PAUSE RESUME PREV NEXT.

SHOW and HIDE at the top take the banner off air without removing the source in OBS.

Along the bottom: UNDO reverses the last change, SWITCH TEAMS swaps sides, CLEAR PICKS & BANS empties the draft, and RESET MATCH starts over.

ใช้กับแมตช์เดี่ยวที่ไม่ได้อยู่ในทัวร์นาเมนต์

  1. ไปหน้า CONTROL
  2. พิมพ์ชื่อทีม หรือเลือกทีมที่บันทึกไว้จากช่อง From registry
  3. พิมพ์ชื่อผู้เล่น
  4. ตอนดราฟต์ พิมพ์ชื่อฮีโร่ในช่อง HERO PICK และ BAN แล้วกด Enter
  5. คุมเวลาด้วย START PAUSE RESUME PREV NEXT

ปุ่ม SHOW กับ HIDE ด้านบน ใช้ซ่อนแถบ overlay โดยไม่ต้องปิด source ใน OBS

ปุ่มแถวล่าง: UNDO ย้อนการแก้ล่าสุด SWITCH TEAMS สลับฝั่ง CLEAR PICKS & BANS ล้างดราฟต์ RESET MATCH เริ่มใหม่ทั้งแมตช์

4
Save teams once, use them everywhere
บันทึกทีมไว้ใช้ซ้ำ
  1. Go to TEAMS → + NEW TEAM.
  2. Fill in the name, tag, players and a logo.
  3. Click CREATE TEAM.

Saved teams appear in From registry on the control panel and can be added to any tournament. Edit a team once and every future match uses the new details.

  1. ไปที่ TEAMS → + NEW TEAM
  2. ใส่ชื่อทีม ตัวย่อ ผู้เล่น และโลโก้
  3. กด CREATE TEAM

ทีมที่บันทึกไว้จะโผล่ในช่อง From registry ของหน้า Control และเอาไปใส่ทัวร์นาเมนต์ไหนก็ได้ แก้ข้อมูลทีมครั้งเดียว แมตช์ต่อๆ ไปได้ข้อมูลใหม่ทั้งหมด

5
Run a tournament
จัดทัวร์นาเมนต์
  1. HOME → + NEW TOURNAMENT, then name, format, best of, and CREATE.
  2. + ADD TEAM — pick saved teams, or create new ones there.
  3. Click OPEN MATCH SESSION, then DRAW MATCHES.
  4. Click a match box to put it on air. The control panel opens with both teams filled in.
  5. Type scores into the bracket. Winners move to the next round by themselves.

Deleting a tournament cannot be undone. The bracket and every draft saved under it go with it. Your teams stay in the registry, with their history in other tournaments intact.

  1. HOME → + NEW TOURNAMENT ใส่ชื่อ รูปแบบ จำนวนเกม แล้วกด CREATE
  2. + ADD TEAM เลือกทีมที่บันทึกไว้ หรือสร้างทีมใหม่ตรงนั้น
  3. กด OPEN MATCH SESSION แล้วกด DRAW MATCHES
  4. คลิกที่กล่องคู่แข่งเพื่อเอาขึ้นจอ หน้า Control จะเปิดพร้อมชื่อทีมทั้งสองฝั่ง
  5. กรอกคะแนนในสาย ผู้ชนะจะเลื่อนไปรอบถัดไปเอง

ลบทัวร์นาเมนต์แล้วกู้คืนไม่ได้ สายการแข่งกับดราฟต์ที่บันทึกไว้หายไปด้วย แต่ทีมในทะเบียนยังอยู่ครบ รวมถึงประวัติในทัวร์นาเมนต์อื่น

6
Add sound effects
ใส่เสียงเอฟเฟกต์
  1. Menu ROV Tool → Open Sounds Folder.
  2. Put your files in, named exactly as below.
  3. Set the volume on CONTROL → Sound effects.
FilePlays
pick.mp3when a hero is picked
ban.mp3when a hero is banned
timer-warning.mp3every second of the last ten

.wav works too, and you do not need all three — anything missing just stays silent. The URLs you copied in step 2 already have sound switched on. TEST plays on this computer only, never on stream.

Keep timer-warning under half a second, because it plays once every second.

The overlay has to stay live for sound to reach viewers. OBS only mixes audio from sources in the scene you are broadcasting, so the overlay must be in that scene, not only in another one. In the source properties leave Shutdown source when not visible unticked — with it on, OBS stops the page every time you switch away, and there is a gap of silence when you come back. Keep the ROV Overlay Tool window open too: closing it stops the server and the overlay goes blank.

Hearing nothing? Open the sound check page — it inspects your files and says exactly what is wrong.

  1. เมนู ROV Tool → Open Sounds Folder
  2. เอาไฟล์เสียงไปวาง ตั้งชื่อให้ตรงตามตารางเป๊ะๆ
  3. ปรับความดังที่ CONTROL → Sound effects
ไฟล์ดังตอน
pick.mp3เลือกฮีโร่
ban.mp3แบนฮีโร่
timer-warning.mp3ทุกวินาทีในสิบวินาทีสุดท้าย

ใช้ .wav ก็ได้ และไม่จำเป็นต้องมีครบสามไฟล์ ไฟล์ไหนไม่มีก็แค่เงียบไป URL ที่ก๊อปไว้ในข้อ 2 เปิดเสียงมาให้แล้ว ปุ่ม TEST ดังที่เครื่องนี้เท่านั้น ไม่ออกอากาศ

ไฟล์ timer-warning ควรสั้นไม่เกินครึ่งวินาที เพราะมันดังทุกวินาที

ต้องเปิด overlay ค้างไว้ตลอด เสียงถึงจะออกไปถึงคนดู OBS ผสมเสียงเฉพาะ source ที่อยู่ในซีนที่กำลังออกอากาศ ดังนั้น overlay ต้องอยู่ในซีนนั้นด้วย ไม่ใช่อยู่แค่ในซีนอื่น และใน properties ของ source อย่าติ๊ก Shutdown source when not visible ถ้าติ๊กไว้ พอสลับซีนออกไป OBS จะปิดหน้านั้นทิ้ง แล้วตอนสลับกลับมาจะเงียบไปพักหนึ่ง อีกอย่างคือต้องเปิดหน้าต่างโปรแกรม ROV Overlay Tool ค้างไว้ด้วย ถ้าปิดโปรแกรม เซิร์ฟเวอร์จะหยุดและ overlay จะกลายเป็นจอเปล่า

ไม่ได้ยินเสียงเลย? เปิด หน้าตรวจเสียง มันจะตรวจไฟล์ให้แล้วบอกว่าติดตรงไหน

7
Change how it looks
เปลี่ยนหน้าตา

Go to DESIGN. Colours, text sizes, logo size and your own background images all live there, and the preview at the top updates as you change things. RESET TO ORIGINAL puts everything back.

ไปหน้า DESIGN ปรับสี ขนาดตัวหนังสือ ขนาดโลโก้ และอัปโหลดภาพพื้นหลังของคุณเองได้ ตัวอย่างด้านบนจะเปลี่ยนตามทันที ถ้าอยากได้ของเดิมคืนให้กด RESET TO ORIGINAL

8
Keyboard shortcuts
คีย์ลัด
Key What it does ทำอะไร

เปลี่ยนได้ที่หน้า Hotkeys คีย์ลัดทำงานเฉพาะตอนที่หน้าต่างโปรแกรมอยู่ข้างหน้าเท่านั้น ไม่ทำงานตอนอยู่ใน OBS หรือในเกม

When something looks wrong
เวลามีอะไรผิดปกติ
What you seeWhat to do
Overlay does not updateRight-click the source in OBS, then Refresh
No sound at allOpen the sound check page, and tick Control audio via OBS in the source properties
Every sound plays twiceOnly one browser source may carry ?sfx=1 in its URL
Sound stops after switching scenesThe overlay must be in the scene you are broadcasting, and Shutdown source when not visible must be unticked
Wrong teams on screenPress RESET MATCH, or put the right match on air again
Replaced a sound, still hear the old oneAdd &v=2 to the end of the source URL, then Refresh

overlay ไม่อัปเดตคลิกขวาที่ source ใน OBS แล้วกด Refresh

เสียงดังซ้อนสองครั้งให้มี ?sfx=1 ใน URL ของ source เดียวเท่านั้น
