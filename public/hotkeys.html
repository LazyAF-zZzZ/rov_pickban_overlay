Control panel hotkeys
Click CHANGE, then press the key you want
These work on the Control Panel while its window has focus. For keys that keep working while you are in OBS or the game, see System-wide hotkeys below.

Tapping a modifier on its own (Alt, Ctrl, Shift) is allowed and is the default for the banner toggle. It fires on release, and only when the key is tapped alone - so Alt+Tab still switches windows without cutting your banner off air.
System-wide hotkeys
Work while OBS or the game has focus
This panel only does anything in the desktop app. A page in a browser cannot register keys with Windows, so nothing here is switchable while you are reading it in one.
The desktop app registers these with Windows itself, so they fire from anywhere - no need to click back into the Control Panel first.

Every one of them needs a modifier (Ctrl, Alt, Shift or Win). A bare key registered system-wide is taken away from every other program on this machine, which would be a strange thing to have happen after installing a broadcast overlay.

A key another program already holds is marked in red here, because the app is told which ones it actually got. Nothing breaks - that one shortcut simply does not fire, and the rest still work.
